# 块间 · 属于你的小小世界

在原有 React / TypeScript / Vite / React Three Fiber / Zustand 项目上改造的微缩小镇经营游戏。程序生成体素场景，无外部模型、账号、收费接口或 AI 服务。

## 本地运行

开发服务器：`http://127.0.0.1:5173/`。安装使用 `npm install`，启动使用 `npm run dev`。`npm run build` 生成 dist，`npm run preview` 预览生产版本。需要 Node.js 22.18+，开发验证环境为 Node.js 24 和 Chrome。

## 这一版的玩法

新局拥有 1000 金币、30 木材、20 食物、2 位居民，以及一间小木屋和公共仓库。沿用原有 3×3 地块结构，初始 9 块土地组成 9×9 的紧凑大陆。

- 建造住宅提供容量；空房、岗位、食品储备和幸福度共同决定入住。居民自动分配住所和工作，新设施优先获得首位员工，避免生产链某一环长期空岗。
- 生产链：农田 → 小麦 → 磨坊 → 面粉 → 面包房 → 面包 → 店铺 → 居民消费。农田还提供基础食物；伐木场和木作工坊提供木材、家具。生产必须有员工，配方会实际消耗库存；与仓库连通的道路恢复完整物流效率。
- 店铺从仓库进货并扣除采购成本。只有居民付款才有营业额，工资和维护持续支出，因此店铺可能亏损。住宅仅向有钱包余额的实际住户收取租金。售价可调整，过高会失去顾客。
- 居民拥有年龄、家庭、住所、职业、钱包、需求、健康、幸福度和近期经历；白天工作、午间用餐、购物、晚间散步、夜间回家。岗位工资默认 30 金币/天，家庭汇款 24 金币/天进入居民钱包，维持小镇内长期消费能力；汇款不会直接进入玩家金库。
- 公园、花坛、树木与长椅改善生活环境；诊所减轻流感。缺食品、失业、健康下降会降低幸福度，长期恶劣条件可能导致搬离。
- 四个小镇等级：起步聚落、6 人村庄、20 人且累计商业收入 150 的小镇、50 人且收入 1000 的小城。已解锁等级不会回退。13 种核心生活设施之外保留原有进阶内容。
- 12 个引导任务与邻里愿望，按真实行为完成、手动领取一次奖励。暴雨、庆典、流感三类有持续时间的随机事件实际影响产量、消费或健康。
- 1 秒推进 4 个游戏分钟；一天 360 秒。支持暂停及 1/2/4 倍速。工作时段 08:00–12:00、13:00–18:00；店铺 08:00–22:00。
- 日报区分店铺销售、租金、工资、维护、采购、生产、消费和人口变化。营业净利润不混入建造、手动交易、拆除或任务奖励。
- 建筑可旋转、搬迁、升级、暂停和拆除；拆除返还基础造价的 50%，库存返仓，住户和员工重新分配。扩地从 300 金币起，费用随土地规模上升。
- 每 10 秒自动保存，也可手动保存、导出/导入 JSON。v2 存档包含完整经营状态，并迁移 v1 存档；旧世界不会被自动重置。

## 操作

底部六类建造按钮对应数字 1–6；点击建筑查看详细经营状态。左键拖动平移、右键或 Shift+左键旋转、滚轮缩放；R 旋转待放置建筑，Esc 取消/关闭。居民、愿望和日报位于底部右侧。长按采集只补充少量木材，主要收入来自实际经营。

## 代码结构

- `src/game/TownSimulation.ts`：不依赖 React 的确定性经营 Tick，包括人口、就业、配方、消费、幸福、事件、任务和日报。
- `src/data/town.ts`：建筑经营参数、等级、任务和初始经营状态；`settlement.ts` 是新局布局。
- `src/stores/useTownStore.ts`：经营状态；保留原有资源、世界、建筑、居民、设置、游戏及 UI stores。
- `src/components/TownHUD.tsx`、`TownPanels.tsx`：经营顶部栏、六类建造入口、居民、供需、建筑、愿望、日报。
- `src/world/`、`src/buildings/`、`src/npcs/`：保留并扩展原有 3D 渲染、相机、体素模型和道路行走。
- `src/systems/persistence.ts`：v2 保存/校验与 v1 兼容迁移。

## 验证

`npm test` 运行纯规则测试；`npm run test:browser` 在本地 Chrome 中执行实际鼠标建造、消费、解锁、保存和手机布局测试，需先启动开发服务器。`npm run test:settings` 验证暂停、速度、昼夜、天气与重新开局。浏览器截图和机器可读结果在 `test-results/`。

旧版电力、异界和室内展示仍保留在代码中。当前核心经营以主世界居民生活为中心，不含云端存档、离线补算、多人与 LLM 驱动 NPC。
