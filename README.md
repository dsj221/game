# 块间 · 属于你的小小世界

在原有 React / TypeScript / Vite / React Three Fiber / Zustand 项目上改造的微缩小镇经营游戏。程序生成体素场景，无外部模型、账号、收费接口或 AI 服务。

## 本地运行

开发服务器：`http://127.0.0.1:5173/`。安装使用 `npm install`，启动使用 `npm run dev`。`npm run build` 生成 dist，`npm run preview` 预览生产版本。需要 Node.js 22.18+，开发验证环境为 Node.js 24 和 Chrome。

## 这一版的玩法

新局拥有 1000 金币、30 木材、20 食物、2 位居民，以及一间小木屋和公共仓库。每块土地仍为3×3格，初始12块土地组成12×9格大陆，比原版多三分之一规划空间。旧存档不会改变土地。

- 建造住宅提供容量；空房、岗位、食品储备和幸福度共同决定入住。居民自动分配住所和工作，新设施优先获得首位员工，避免生产链某一环长期空岗。
- 生产链：农田 → 小麦 → 磨坊 → 面粉 → 面包房 → 面包 → 店铺 → 居民消费。农田还提供基础食物；伐木场和木作工坊提供木材、家具。生产必须有员工，配方会实际消耗库存；原料和成品在建筑库存之间由搬运员、推车沿道路运输，堵塞时场外堆货并最终停工。
- 店铺从仓库进货并扣除采购成本。只有居民付款才有营业额，工资和维护持续支出，因此店铺可能亏损。住宅仅向有钱包余额的实际住户收取租金。售价可调整，过高会失去顾客。
- 居民拥有年龄、家庭、住所、职业、钱包、需求、健康、幸福度和近期经历；白天工作、午间用餐、购物、晚间散步、夜间回家。岗位工资默认 30 金币/天，家庭汇款 24 金币/天进入居民钱包，维持小镇内长期消费能力；汇款不会直接进入玩家金库。
- 前 8 位焦点居民会因长通勤、食品短缺、健康、休闲、购物或住宅周边布局产生独立个人愿望。每个愿望有截止日和至少两种空间/经营解法；解决或错过后会留下长期记忆，但不会扣除资源或制造死档。
- 公园、花坛、树木与长椅改善生活环境；诊所减轻流感。缺食品、失业、健康下降会降低幸福度，长期恶劣条件可能导致搬离。
- 五个小镇等级：初生聚落、温暖村庄、热闹小镇、繁荣城镇、梦想之城。晋级人口要求为6/20/50/100，近期营业额要求为0/150/1000/3000；幸福度分别至少45/70/70/70。条件满足弹出提示，玩家确认后晋级，可稍后在邻里愿望中继续。已解锁等级不会回退。
- 27个引导任务与邻里愿望分为五章，覆盖直到Lv.5的经营进程。当前章节开放操作，未来章节可预览；已领取任务默认折叠。按钮直接进入所需建筑的放置模式并定位空地，或定位已有生产设施/居民供需/晋级入口。每项包含具体操作说明，奖励只领取一次。暴雨、庆典、流感三类事件持续影响产量、消费或健康。
- 1 秒推进 4 个游戏分钟；一天 360 秒。支持暂停及 1/2/4 倍速。工作时段 08:00–12:00、13:00–18:00；店铺 08:00–22:00。
- 日报区分店铺销售、租金、工资、维护、采购、生产、消费和人口变化。营业净利润不混入建造、手动交易、拆除或任务奖励。
- 建筑可旋转、搬迁、升级、暂停和拆除；拆除返还基础造价的 50%，库存保留在原址等待搬运，住户和员工重新分配。扩地从 300 金币起，费用随土地规模上升。
- 家具、陶器与工具已拆分：家具用于高等级住宅升级，陶器进入餐饮与节庆消耗，工具由手工作坊生产并维持生产设施效率。缺少工具只让生产周期慢 10%，不会锁死基础产业链。
- 相邻建筑会形成“块间反应”：面包与木作供应链生成连廊/料架，住宅与绿地长出共享花篱，商店临街开摊并在相邻店铺间挂起灯彩。首版含 16 条高频规则，实际影响生产效率、邻里幸福与商业客流，详情面板会解释来源；密集堆叠设有收益上限。
- 每 10 秒自动保存，也可手动保存、导出/导入 JSON。v2 存档包含完整经营状态，并迁移 v1 存档；旧世界不会被自动重置。

## 操作

底部六类建造按钮对应数字 1–6；点击建筑查看详细经营状态。左键拖动平移、右键或 Shift+左键旋转、滚轮缩放；R 旋转待放置建筑，Esc 取消/关闭。居民、愿望、日报和街区手记位于底部右侧。地图中央的块间手记会展示建筑相邻形成的街区故事；金币既可来自实际经营、委托和交易，也可按住“获取金币”积累林间馈赠。

## 代码结构

- `src/game/TownSimulation.ts`：不依赖 React 的确定性经营 Tick，包括人口、就业、配方、消费、幸福、事件、任务和日报。
- `src/data/town.ts`：建筑经营参数、等级、任务和初始经营状态；`settlement.ts` 是新局布局。
- `src/stores/useTownStore.ts`：经营状态；保留原有资源、世界、建筑、居民、设置、游戏及 UI stores。
- `src/components/TownHUD.tsx`、`TownPanels.tsx`：经营顶部栏、六类建造入口、居民、供需、建筑、愿望、日报。
- `src/world/`、`src/buildings/`、`src/npcs/`：保留并扩展原有 3D 渲染、相机、体素模型和道路行走。
- `src/systems/persistence.ts`：v2 保存/校验与 v1 兼容迁移。

## 验证

`npm test` 运行纯规则测试；`npm run test:browser` 在本地 Chrome 中执行实际鼠标建造、消费、解锁、保存和手机布局测试，需先启动开发服务器。`npm run test:settings` 验证暂停、速度、昼夜、天气与重新开局。浏览器截图和机器可读结果在 `test-results/`。

块间反应另有 `node tests/spatial-reactions-browser.mjs` 视觉冒烟测试。模拟热路径使用每 Tick 空间影响缓存、矩形占地距离和居民/建筑索引；本地 Node 压测从约 159ms/Tick 降到约 16–18ms/Tick（500 居民、167 建筑），300 居民的 60 次采样平均约 10ms，仍需继续推进分帧决策以达到 6ms 目标。

旧版电力、异界和室内展示仅为旧存档兼容保留，不再进入主建造图鉴。当前核心经营以主世界居民生活和块间规划为中心，不含云端存档、离线补算、多人与 LLM 驱动 NPC。

季节采用14日一季，包含两天预报、河道水位、可调蓄水闸、连通水渠和真实水力发电。点击右上角季节进入日报施工图，Lv.2可建设河畔水轮机。机制与验证见 [docs/SEASONS.md](docs/SEASONS.md)。

物流以面包、家具、工具三条主链为重点，未新增资源种类。日报及建筑详情可查看室内库存、场外堆货、在途货物，并设置仓库收货优先级。详见 [docs/LOGISTICS.md](docs/LOGISTICS.md)。
