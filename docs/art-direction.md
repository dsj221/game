# 美术方向：手绘木质微缩沙盘与东方乡野

统一颜料见 `src/data/artDirection.ts`：橙木、青瓦、红砖、灰石与暖纸色。沿用已有建筑轮廓、瓦片、木纹和原画图标，模型材质与界面围绕同一组颜色组织。

每七个游戏日换季，28日一轮。地表、模型里的绿色植被与居民衣服同步变化；夏季居民增加宽檐帽，冬季增加围巾。季节目前只影响美术，不改变生产数值。季节由游戏日推导，旧存档无需新增字段。

地面采用连续区域色差，边缘带斜坡草皮和土壤分层。道路旁有草、空地有磨损、农田有田埂、水边有沙石过渡。地景按位置确定，建造不会随机重排。

磨坊转轮、面包房及窑炉炊烟、商铺遮阳棚受经营状态控制；缺工、缺料、休息和停用时停止对应工作表现。仓库堆货数量随全镇仓储库存变化。选中或悬停设施时，地图标签展示营业状态、当日净额和店内库存。

公共工程在原建筑占地内增建：共享粮仓的储粮塔、匠社的牌楼、公共服务的钟亭、花园的花架、博览会的庆典旗帜。这些变化跟随现有工程存档恢复。

验收：`node tests/art-direction-browser.mjs` 检查四季着色、着色器编译、五个工程模型、休息后的烟雾与棚布变化、地图信息和手机布局，并输出截图到 `test-results/art-*.png`。
