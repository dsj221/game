# 块间 · KUAI–BLOCK

一个可在本地浏览器运行的原创体素微缩经营游戏。无需账号、模型下载或收费 API。

## 运行

需要 Node.js 22.18+（开发环境使用 Node.js 24）。

```sh
npm install
npm run dev
```

游戏地址：http://127.0.0.1:5173。生产构建使用 `npm run build`，本地预览使用 `npm run preview`。

## 已实现的玩法

- 主世界 20 块地、下界 6 块地、末地 5 块地，建筑与居民数据彼此独立；所有世界持续生产。
- 正交 3D 相机：左键平移、右键或 Shift + 左键旋转、滚轮缩放，支持阻尼与镜头重置。
- 配置驱动的 24 种建筑：购买、网格放置、边界与占用检测、旋转、搬迁、升级、扩地。
- 晶体、木材、石头、铁矿、红石、食物、人口和能源经济；每秒结算，0 / 1 / 2 / 4 倍速。
- 长按采集，每次 +60 起步晶体与材料；20 次采集触发共振，奖励 1,500 晶体并充满能源。
- 生产建筑与道路必须连通集市或仓库才获得完整物流效率；孤立设施保持 50% 产出。
- 能源不足时机器停机；发电设施恢复动力。居民食物耗尽时经营收入下降。
- 村民、铜傀儡、铁傀儡，沿道路移动、工作和搬运；可招募新伙伴，受住宅容量限制。
- 资源集市动态价格、买入与卖出；16 项基于行为的成就与设施图鉴。
- 独立 3D 直播室：节目、拍摄机位、观众增长、频道收入、订单、礼物、设备和室内布置。
- 天气、昼夜、雨雪、萤火虫、流星、灯饰、气象台、程序生成音效。
- 每 10 秒自动 localStorage 保存，页面关闭前保存，JSON 导出与校验导入、新游戏。

初始财富为 6,500 晶体，界面上的数值全部来自真实游戏状态。大型展示数字没有硬编码。

## 目录

```text
src/
  components/    中文面板、设施缩略图、设置窗口
  game/          建造、采集、交易、升级、直播与 Tick 动作
  world/         3D 大陆、相机、粒子、场景细节、直播室
  buildings/     原创程序化 voxel 模型
  npcs/          人物模型与道路行为
  systems/       经济规则、物流、存档校验与声音
  stores/        七个独立 Zustand store
  data/          建筑配置、世界配置、成就和初始布局
  hooks/         游戏时钟、快捷键和自动保存生命周期
  utils/         数字显示
  types/         TypeScript 数据类型
tests/           经济规则单元测试与真实 Chromium 交互测试
test-results/    本地测试截图与报告（不提交）
```

## 技术

React 19、TypeScript、Vite、Three.js、React Three Fiber、drei、Zustand、Framer Motion、Lucide。UI 使用自定义 CSS，所有 3D 模型由几何体生成；地面与道路使用 InstancedMesh。字体使用系统字体，不请求外部 CDN。

## 验证

```sh
npm test
npm run build
npm run test:browser
```

浏览器测试需先启动开发服务器。默认使用 Windows Chrome；其他系统通过环境变量 `CHROME_PATH` 指定 Chromium 可执行文件。测试新建隔离的浏览器上下文，不会改动玩家浏览器存档。开发模式提供只读诊断入口给测试，生产构建不暴露该入口。

## 首版范围与可扩展方向

这是本地单人经营沙盒，没有多人联机和云存档。物流采用道路连通性简化规则，不逐件模拟每份货物；NPC 采用道路 waypoint 行为。直播是本地模拟经营系统，不连接实际直播平台。后续可继续加入复杂生产配方、剧情任务、更多建筑外观、地形编辑与大型地图优化。60 FPS 是目标，实际帧率取决于 GPU、窗口大小和建筑数量。
