# 可见货运

本次保留面包、家具、工具三条主链，未增加资源种类。既有材料和配方继续兼容旧存档。

## 玩家操作

点击右上角季节进入日报，查看“可见货运”；选中建筑后，也可在建筑详情查看它的库存和运输任务。仓库或集市支持低、普通、高三个收货优先级。

- 普通建筑室内容量每级24件；仓库/集市每级80件。生产原料从本建筑库存消耗，成品先留在本建筑；店铺只从到货库存采购到货架。
- 每级仓库/集市配一名搬运员和一辆推车，最高各3名。搬运员每趟4件、推车8件，自动执行取货、装载、移动和卸货。它们是仓储自带的运输队，不占现有生产岗位。
- 补料任务优先，按建筑轮流调度，避免一条链长期占据全部运力。成品回仓按玩家优先级选择可达且有空间的仓库；不可达时尝试下一座。集市保留零售缓冲库存，避免被其他仓库反复搬走。
- 建筑入口必须接上完整道路。搬运员走得较慢，推车更快；不同道路有不同通行耗时，泥泞进一步减速。同一格每tick允许一名搬运员/推车进入，其他车辆等待后重试。
- 断路时，尚未运走的成品堆在建筑外；库容或运力不足也会逐渐形成堆货。场外货物达到本建筑室内容量时，生产暂停，等待运走后恢复。在途断路时保留车上的货物，修路后继续。
- 住宅的应急口粮、冬季木材以及工坊维护工具，也需要运送到本地。

## 库存与存档

顶部可用库存代表仓库/集市及原址仓储物资，不包含生产建筑库存、店铺货架和在途货物。货物送达仓库才加入可用库存；玩家交易和建材支出在下一模拟tick与仓储实物对账。货架采购只转移一次货物，不重复生成仓储库存。

拆除建筑保留原址待回收物资；载货车辆在目的建筑拆除后寻找可用仓库。没有仓库的旧地图使用临时料场保留原始库存。有地图的游戏默认启用实际货运；无地图的纯经济测试保留原有简化结算路径。

室内库存、场外堆货、仓库优先级、搬运员位置、路径和在途货物均持久化。导入时校验资源种类、非负数量、载量上限和路线结构。旧存档首次运行时从既有可用库存初始化仓储，不清空原有货物。

## 验证

- `npm test`：涵盖货物守恒、优先级、断路/修复、拆除回收、拥堵恢复、加工等待、堆货停工、集市账务及家具/工具完整成交；面包链沿用地图闭环测试。
- `npm run build`：类型检查与生产构建。
- 开发服务启动后运行 `node tests/logistics-browser.mjs`：验证优先级控件、货箱渲染、实际修路、载货移动、在途存档重载和最终入仓。

## 物流地图、仓储规则与主链诊断

点击「物流地图与主链诊断」进入日报：蓝线表示前往取货，绿线表示已装货的送货路线，橙色表示等待通行，红色提示标记未接道路或断开的建筑。点击场外堆货可查看原因并定位建筑。

每座仓库和集市均可对现有物资设置允许储存、最低储备、目标库存。规则即时保存到城镇状态并随存档恢复；最低储备禁止派车外运、建造、升级、工程和外贸消耗，降低储备可释放。集市自己的货架补货仍可使用本地库存。目标值限制新运输任务，已经派出且装货的任务仍完成交付。容量为所有物资共享，多个目标之和可以超过容量，届时按派车顺序使用空间。没有符合规则的仓位时，外部新增物资留在卸货点，仍可回收。

三条生产链显示各建筑的本地库存、货架、已装货在途数量、今日实际产出和截至当前游戏时间的平均产速；商店显示今日成交人次。产量按游戏日清零，不是理论最大产能。列出未建设环节与员工不足、原料短缺、堆货停工等状态，点击已有建筑定位。工具链的木材与铁矿为并行投入。

## 运力经营与工作餐

每座仓库及集市可独立配置 0–6 名搬运员和 0–6 辆推车，以及上班、下班、午休时间，支持跨午夜。旧存档默认每级一名搬运员和一辆推车（最多各三），全天工作。搬运员满日工资 6，推车含驾驶员满日工资 8，每辆车每日维护 2；排班时段即使闲置也支付工资，暂停仓库不计运输费用。运输队属于雇佣服务，不重复占用居民岗位。

缩编或下班后完成已接单任务，继续计薪；任务完成后退出，不丢失货物。运输费用计入日报工资／维护和建筑经营成本。面板显示计划日支出与今日累计支出。

有员工的建筑接受食物配送，员工在工作场所可吃储备粮。非必要购物安排在班外，严重饥饿可外出用餐；居民不会再反复前往买不起的商店，有家中储备粮时会回家用餐。补货轮流调度以避免远处工坊饿死，同一需求优先就近取货；食物优先于该建筑的普通原料补货。普通补货不足一件暂缓合并；工具等低目标库存以半目标为补货阈值，避免小数残量导致永久不补货。
