# 季节与地图事件

每季14个游戏日，全年56日。每个游戏日仍为360个模拟tick，暂停和倍速沿用游戏时钟。

- 春季第5–9日暴雨：土地每日积水，含水量超过75时农业效率65%，泥路使搬运员与推车通行耗时增加至2.5倍。停雨后含水逐日下降，泥痕随排水消退。
- 夏季第4–7日游客节：沿用游客消费行为，成交价格提高30%，地块留下彩带。第9–13日缺水：土地每日失水22，低于25时农业效率45%。
- 秋季农业效率140%，商店成交价格提高15%；第5–11日秋收活动为农业地块留下麦茬。
- 冬季农业效率45%，每位主世界居民每天取暖消耗1木材；不足会损害健康。第4–12日寒潮沿用诊所范围和排班的健康保护。

右上角显示季节日历，事件开始前两天显示预报。点击进入日报查看准备说明、地块含水与工程。已有物资交易和建筑班次系统继续供玩家备粮、储柴、调整服务时段。

水渠每地块消耗5木材和5石材，永久保存；立即排去超过70的积水，暴雨日仅增加5水分、干旱日失水8。水渠不会凭空补水。已接入河道、水位、连通水渠与水力发电，详见下文。石井从四格内河道补给的地下水取水，灌溉三格内土地；枯水时也会失去供水。水塔保留原有农业服务加成。

泥泞、干裂、麦茬、积雪、彩带和水渠在3D地图显示，位置与含水、工程状态随存档持久化。旧存档在首次模拟时初始化地块状态，不追溯过去的天气损失。旧65秒随机事件在下一tick切换至当前季节事件。

验证：`npm test`、`npm run build`、开发服务启动后 `node tests/climate-browser.mjs`。浏览器测试覆盖工程扣料、界面更新、存档验证和无运行时错误。


## 河道、水渠与水力发电

地图西侧 x=-6 为南北贯通河道，沿 z 增大方向逐格流动，随着土地扩张延伸。每段独立保存水量和过流量，100 水量对应 1 m 水位。模型采用一维逐段水量收支，不使用真实三维流体求解。

- 上游每秒正常来水0.5，暴雨1.1，旱季0.015；蒸发、下游流出、引水与土壤吸水均从可用水中扣除。每tick只移动到相邻下游段，避免同一滴水瞬间流过全图。新增河段从空河床开始进水，旧存档首次接入时初始化基础水位。
- 河岸超过0.9 m会浸湿相邻地块，形成泥泞并影响农业和作业效率。水面高度随水量变化，枯水显露河床。
- 日报中的“河道·蓄水与水力”提供施工图。选空地或建筑地块可铺设地下水渠；四向相邻即连通，必须接到河道才能引水。每段水渠最多存水10，每秒每段最多引水0.06、灌溉消耗0.015，土壤含水达到65后停止灌溉。取水从河道真实扣除；河道低于0.18 m停止取水，断开的水渠只能使用已有存水。
- 蓄水闸消耗20木材、30石材，建于当前河道中段。提供关闭、25%放流、全开三个开度。关闸保留上游来水，但下游继续流走已有河水；超过3 m自动溢流。低开度节约储水，同时降低下游可用水量和发电。
- Lv.2解锁河畔水轮机：650金币、15木材、10石材。必须在河道或相邻岸边建造，按水位和真实过流量发电，每级最高12 E/秒；同段多机按等级共享水力。静水、枯水、暂停或远离河道时不发电。接入现有480 E能源池，电力耗尽后熔炉等设施真实停机。
- 河道阻挡徒步穿越，木栈桥恢复通行。新建、移动、旋转建筑均检查完整占地，防止填堵河道；既有建筑保留。
- 闸门开度、水量、水渠存水及水轮机随存档保存。导入校验拒绝负水量、重复河段、越界位置和无效开度。

验证：109项单元测试通过，新增水量守恒、旱季停机、蓄放水、断渠、发电分摊、桥梁寻路、扩张与旧存档初始化测试。运行开发服务后执行 node tests/hydrology-browser.mjs 验证工程扣料、选址、实际发电、存档重载和地图渲染。
